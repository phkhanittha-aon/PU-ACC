# ส่วนที่ 1 — ส่งให้ผู้ดูแล SAP Business One

> **เรียนผู้ดูแลระบบ SAP Business One**
>
> เรากำลังทำระบบภายในสำหรับ**รวมเอกสารและติดตามสถานะ**ระหว่างจัดซื้อ QC คลัง และบัญชี
> ระบบนี้**ไม่แทน B1** และ **ไม่เขียนอะไรกลับเข้า B1 เลย** — ขอเพียง**อ่านข้อมูล**บางส่วน
> เพื่อไม่ให้พนักงานต้องพิมพ์เลข PO และเลขผู้ขายซ้ำด้วยมือ
>
> การเชื่อมต่อที่เสนอคือ **โปรแกรมเล็ก ๆ รันบนเครื่องในออฟฟิศ อ่าน B1 แล้วส่งออกไปยัง Google Drive**
> — เป็นการเชื่อมต่อ**ขาออกอย่างเดียว ไม่ต้องเปิดพอร์ตเข้ามาที่เซิร์ฟเวอร์ และไม่ต้องเปิด B1 ออกอินเทอร์เน็ต**
>
> รบกวนช่วยตอบ 6 ข้อด้านล่าง ส่วนใหญ่ได้จากคำสั่ง SQL ที่แนบมา

## 1.1 คำถาม

| # | คำถาม | ทำไมต้องรู้ |

## 1.3 คำสั่ง SQL ที่ขอให้รันแล้วส่งผลกลับมา

> ทั้งหมดเป็น `SELECT` ไม่มีการแก้ไขข้อมูล · ไวยากรณ์ MS SQL (ถ้าเป็น HANA แจ้งได้ เดี๋ยวแปลงให้)

```sql
-- (1) รุ่นของ B1
SELECT Version FROM CINF;

-- (2) เงื่อนไขชำระที่ใช้จริง เรียงตามที่ใช้บ่อย  ← สำคัญที่สุด
SELECT  t.GroupNum, t.PymntGroup, t.NumOfInst, t.ExtraDays, t.ExtraMonth, t.StartFrom,
        COUNT(p.DocEntry) AS UsedInPO
FROM    OCTG t
LEFT JOIN OPOR p ON p.GroupNum = t.GroupNum
GROUP BY t.GroupNum, t.PymntGroup, t.NumOfInst, t.ExtraDays, t.ExtraMonth, t.StartFrom
ORDER BY UsedInPO DESC;

-- (3) ปริมาณใบสั่งซื้อย้อนหลัง 12 เดือน  ← ใช้ยืนยันว่า Google Sheets รับไหว
SELECT  FORMAT(DocDate,'yyyy-MM') AS Period, COUNT(*) AS POs
FROM    OPOR
WHERE   DocDate >= DATEADD(month,-12,GETDATE())
GROUP BY FORMAT(DocDate,'yyyy-MM')
ORDER BY Period;

-- (4) ใบสั่งซื้อที่ยังเปิดอยู่ตอนนี้  ← ใช้เป็นยอดตั้งต้นตอนเริ่มระบบ
SELECT COUNT(*) AS OpenPO FROM OPOR WHERE DocStatus = 'O' AND CANCELED = 'N';

-- (5) ฟิลด์ที่บริษัทเพิ่มเอง (UDF) บนเอกสารที่เกี่ยวข้อง
SELECT TableID, AliasID, Descr FROM CUFD
WHERE  TableID IN ('OPOR','POR1','OCRD','OITM','OPDN','OPCH');

-- (6) ชุดเลขที่เอกสารของใบสั่งซื้อ (ObjectCode 22)
SELECT Series, SeriesName, InitialNum, NextNumber FROM NNM1 WHERE ObjectCode = '22';

-- (7) ตัวอย่างข้อมูลจริง 5 แถว (ปิดบังได้ถ้าต้องการ)
SELECT TOP 5 DocEntry, DocNum, CardCode, CardName, DocDate, DocDueDate,
             DocTotal, DocCur, GroupNum, DocStatus, UpdateDate
FROM   OPOR ORDER BY DocEntry DESC;
```

**ข้อ (2) และ (5) สำคัญที่สุด** — ข้อ 2 ใช้แปลงเป็นงวดจ่ายอัตโนมัติให้ตรงกับสัญญา
ข้อ 5 บอกว่าบริษัทเพิ่มฟิลด์อะไรไว้เองบ้าง ซึ่งมักเป็นข้อมูลที่ใช้จริงในงานประจำวัน

## 2.9 คำถามปิดท้าย ถามทุกคน 3 ข้อ

1. **ถ้าใช้ระบบนี้ งานอะไรของคุณที่จะหายไป** — ถ้าตอบไม่ได้ แปลว่าเรายังไม่ได้แก้ปัญหาของเขา
2. **มีอะไรที่ทำในระบบแล้วช้ากว่าทำแบบเดิมไหม** — ข้อนี้สำคัญกว่าคำชม
3. **อะไรที่คุณกลัวที่สุดถ้าต้องเปลี่ยนมาใช้ระบบนี้** — มักได้คำตอบที่ไม่มีในเอกสารออกแบบเลย
