# 20 — เช็คลิสต์ทดลองใช้งาน (UAT) Phase 1

สำหรับพนักงานที่ร่วมทดลอง — ทำตามข้อของแผนกตัวเอง ใช้เวลาประมาณ 15 นาที

**ก่อนเริ่ม**: เปิดลิงก์ระบบด้วย **บัญชี Google ของบริษัท** (ไม่ใช่บัญชีส่วนตัว)
ถ้าขึ้นว่า *"อีเมลของคุณยังไม่มีในระบบ"* แจ้งหัวหน้าแผนกให้เพิ่มชื่อก่อน

**เจอปัญหาให้กดปุ่ม "แจ้งปัญหา" มุมขวาบนทันที** — ไม่ต้องรอสรุปตอนท้าย
ข้อความจะเข้ากลุ่ม Lark ทันที นี่คือสิ่งที่เราต้องการจากช่วงทดลองมากที่สุด

## สิ่งที่เราอยากรู้จากคุณมากที่สุด

ตอบสั้น ๆ ผ่านปุ่มแจ้งปัญหา หรือบอกหัวหน้าแผนก

1. **ขั้นตอนไหนที่ทำในระบบแล้วช้ากว่าทำแบบเดิม** — บอกมาตรง ๆ ได้
2. **มีช่องไหนที่ต้องกรอกแล้วคุณไม่รู้ว่าเอาข้อมูลมาจากไหน**
3. **มีข้อมูลอะไรที่คุณต้องใช้แต่ระบบไม่แสดงให้ จนต้องไปถามในไลน์อยู่ดี**
4. **แจ้งเตือนใน Lark มากไปหรือน้อยไป**

ช่วงทดลองนี้ไม่ได้มีไว้พิสูจน์ว่าระบบดี แต่มีไว้หาว่ามันยังไม่ดีตรงไหน
ก่อนจะลงทุนต่อ API กับ SAP
